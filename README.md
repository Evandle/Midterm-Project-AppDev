# VERITAS

A merch store built with Blazor (C#) and Tailwind CSS. Visitors can browse merch, view product details, add items to a cart, and sign up for a monthly random Lucky Box.

This is a front-end project: there is no database. The product list lives in code, the cart is kept in memory, and the subscription form and checkout are demos (no payment is taken and nothing is saved).

## Features

- **Home:** a banner carousel, a "Best products" row with numbered cards, a "New arrivals" grid and a Lucky Box promo.
- **Merch:** all products with search, category filter, "in stock only" toggle and sorting.
- **Item:** product details with quantity stepper, live total, wish button, Add to cart and related products.
- **Cart:** change quantities, remove items, see the subtotal and check out. The cart count in the header updates live.
- **Lucky Box:** pick a plan and sign up with a validated form.
- **Responsive:** works on phone, tablet and desktop widths.

## How to run

You need the .NET SDK that matches the project's `TargetFramework` (see the `.csproj` file). Run both commands from the project folder (the one that contains the `.csproj`), each in its own terminal.

1. Tailwind (builds `wwwroot/app.css` from `Styles/tailwind.css`):

   ```
   npx @tailwindcss/cli -i ./Styles/tailwind.css -o ./wwwroot/app.css --watch
   ```

   Run `npm install` once first. If you use the standalone Tailwind CLI instead, replace `npx @tailwindcss/cli` with `./tailwindcss.exe`.

2. The site:

   ```
   dotnet watch
   ```

Then open the address that `dotnet watch` prints.

## Project structure

```text
Components/
  Layout/        MainLayout (header, footer, cart count) and NavMenu
  Pages/         Home, Merch, Item, Cart, Subscribe
  HeroCarousel   the banner on the home page
  ProductCard    one product tile, used on Home, Merch and Item
Models/          Product, HeroSlide
Data/            ProductCatalog: the one list of products
Services/        CartService: the shared cart
Styles/          tailwind.css (Tailwind input file)
wwwroot/         app.css (generated by Tailwind) and images
```

## Notes and limitations

- The cart lives in memory, so refreshing the browser empties it.
- The Account icon in the header is a placeholder.
- Product data is edited in `Data/ProductCatalog.cs`.
